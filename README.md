
# CodeAlpha Fitness Tracker

A responsive fitness tracking web application developed for CodeAlpha App Development Internship — Task 3.

## Features

- Track daily steps and monitor progress toward a 10,000-step goal.
- Log workouts with exercise name, duration, and calories burned.
- View daily activity statistics.
- Visualize steps and calories through a weekly activity chart.
- Monitor daily goals using progress bars and a circular progress indicator.
- Save fitness data in browser local storage.
- Responsive dark-themed dashboard for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage

## Project Structure

- `index.html` — Application structure and dashboard.
- `style.css` — Styling and responsive layout.
- `script.js` — Fitness tracking logic, data storage, and chart functionality.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Ensure you have an internet connection for the Chart.js library.
